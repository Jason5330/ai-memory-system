<h1>機制與工具總覽（Mechanisms &amp; Tools Reference）</h1>

<blockquote>這份把框架裡所有<strong>確定性腳本（lib/ 與其他）</strong>和<strong>機制</strong>整理成一張地圖。<br>看白話入門：<code>新手指南.md</code>；看指令用法：打 <code>/help</code>；看名詞中文：<code>記憶名詞對照表.md</code>。</blockquote>

<hr>

<h2>核心設計哲學：AI 判斷 ⊥ 確定性腳本</h2>

<p>整個框架只有一條主軸——<strong>讓 AI 做它擅長的「語意判斷」，讓腳本做它擅長的「確定性執行」</strong>：</p>

<table><thead><tr><th>層</th><th>誰做</th><th>性質</th><th>例子</th></tr></thead><tbody><tr><td>判斷</td><td><strong>AI</strong>（讀 markdown 指令/入口檔）</td><td>盡力而為、語意</td><td>這值不值得記？這是不是同一個工作流？這是機械程式還是判斷工作流？</td></tr><tr><td>執行</td><td><strong>確定性腳本</strong>（lib/ 等）</td><td>100% 可重現</td><td>原子寫檔、計次、備份/校驗/回滾、硬擋、跑存好的程式</td></tr></tbody></table>

<p><strong>所以每個機制都是「AI 判斷 → 交給腳本安全執行」</strong>。腳本放在 <code>~/.ai-memory/lib/</code>（個人層、跨專案）。</p>

<hr>

<h2>Part 1 — <code>lib/</code> 三大工具</h2>

<h3>1. <code>memory-write.{ps1,sh}</code> — 安全寫入器（Hermes 式外殼）</h3>

<p>把「最怕寫壞」的兩種寫入交給確定性腳本：<strong>空內容擋、重複擋(dedup)、檔鎖、先讀磁碟最新、temp+rename 原子寫、drift 先備份(.bak)</strong>。</p>

<table><thead><tr><th>模式</th><th>用途</th><th>指令</th></tr></thead><tbody><tr><td><code>append</code></td><td>安全追加一段內容到檔案（去重）</td><td><code>memory-write.ps1 -Mode append -File &lt;path&gt; -Content &quot;&lt;block&gt;&quot;</code></td></tr><tr><td><code>block-tool</code></td><td>原子加一條到硬擋註冊表</td><td><code>memory-write.ps1 -Mode block-tool -Tool &lt;Name&gt; -Reason &quot;...&quot; -UseInstead &quot;&lt;Alt&gt;&quot; -Platform both</code></td></tr></tbody></table>

<ul><li><strong>退出碼</strong>：<code>0</code> 寫入 · <code>0</code>(印 SKIP) 重複不動 · <code>2</code> 空內容拒絕 · <code>3</code> 鎖忙 · <code>4</code> 寫錯。</li><li><strong>誰呼叫</strong>：<code>/capture</code> Step 2.5（壞工具進硬擋）、Memory Decision Gate 的安全類別 append。</li><li><strong>範圍刻意收斂</strong>：只用在硬擋註冊表 + append-only 檔；knowledge 頁要語意合併，仍由 AI 編輯。</li></ul>

<h3>2. <code>detect-repeats.{ps1,sh}</code> — 重複工作流偵測器（確定性計次）</h3>

<p>掃兩層 <code>conversations/*.md</code> 的 <code>🔁 repeat:&lt;slug&gt;</code> 標籤<strong>精準計次</strong>、<strong>排除已有同名 skill</strong>、列出 <strong>seen ≥ 門檻且尚無 skill</strong> 的工作流。</p>

<pre><code>detect-repeats.ps1 [-Threshold 2] [-ProjectPath &lt;dir&gt;] [-Json]</code></pre>

<ul><li><strong>計次不分時間地點</strong>：同一 session（同一檔多筆）／同天／跨 session／跨層一律累加。</li><li><strong>退出碼</strong>：恆 <code>0</code>（唯讀報告）。<code>-Json</code> 給機器讀。</li><li><strong>誰呼叫</strong>：<code>/capture</code> Step 4、<code>/dream</code> Phase 3c、<code>/status</code>、<strong>入口檔 session-start 第 5 步</strong>（一開 session 就提醒）。</li><li><strong>輸出純 ASCII</strong>（PS 5.1 會把無 BOM 的 .ps1 非 ASCII 字面誤解碼）；中文提醒語由 AI 講。</li></ul>

<h3>3. <code>tool.{ps1,sh}</code> — Saved Tools 執行器</h3>

<p>「寫好的程式存起來，下次同樣請求直接跑、不重寫」。<strong>不是 skill（playbook），是一支直接執行的程式。</strong></p>

<table><thead><tr><th>子指令</th><th>用途</th></tr></thead><tbody><tr><td><code>list</code></td><td>列出已存的工具（slug／描述／觸發語）</td></tr><tr><td><code>run &lt;slug&gt; [args]</code></td><td><strong>直接執行</strong>存好的程式（轉送<strong>位置</strong>參數）</td></tr><tr><td><code>add &lt;slug&gt; -Desc &quot;...&quot; -Triggers &quot;a;b;c&quot; -Script &lt;path&gt;</code></td><td>把能用的程式複製進 <code>tools/&lt;slug&gt;.{ps1,sh}</code> 並註冊觸發語</td></tr><tr><td><code>path &lt;slug&gt;</code></td><td>印出該工具的程式路徑</td></tr></tbody></table>

<ul><li><strong>註冊表</strong>：<code>~/.ai-memory/tools/tools.json</code>（觸發語 → 程式）；程式本體放 <code>~/.ai-memory/tools/&lt;slug&gt;.{ps1,sh}</code>。</li><li><strong>退出碼</strong>：<code>0</code> ok · <code>2</code> 找不到 · <code>3</code> 用法錯 · <code>4</code> 執行錯。</li><li><strong>誰呼叫</strong>：入口檔「Saved tools」規則——① 寫程式前先 <code>list</code> 查、命中就 <code>run</code>；② 寫好可重複的程式就問要不要 <code>add</code>。</li><li><strong>限制</strong>：<code>run</code> 轉送<strong>位置參數</strong>；<code>-Named</code> flag 會被 wrapper 的參數綁定攔截 → 存的工具請設計成吃位置參數或環境變數。</li></ul>

<h2>Part 6 — 踩過的環境雷（Windows / PowerShell 5.1）</h2>

<p>這些都已在腳本內修掉並驗證，列出供維護參考：</p>

<ul><li><strong>無 BOM 的 .ps1 非 ASCII 字面 → cp950 誤解碼破壞解析</strong> → 腳本輸出/比對改純 ASCII，中文放 markdown 由 AI 講。</li><li><strong><code>Get-Content -Raw</code> 讀 UTF-8 無 BOM 中文 → 誤解碼</strong> → 改 <code>[IO.File]::ReadAllText($p,[Text.Encoding]::UTF8)</code>。</li><li><strong>變數名稱大小寫不敏感</strong>：<code>$SETTINGS</code>(路徑) 與 <code>$settings</code>(物件) 是同一個 → 用不同名（<code>$settingsObj</code>）。</li><li><strong>regex 尾錨點 <code>$</code> 配 em-dash 回溯</strong> → slug <code>md-to-html</code> 被切成 <code>md-to</code>：改用 ASCII <code>repeat:</code> token、去尾錨點。</li><li><strong><code>tool run</code> 的 <code>-Named</code> 參數被 wrapper 攔</strong> → 存的工具設計成吃位置參數/環境變數。</li><li><strong><code>Remove-Item &lt;變數&gt; -Recurse -Force</code> 被沙箱靜態攔下</strong> → 用 <code>[IO.Directory]::Delete($p,$true)</code>。</li><li><strong>git-bash 的 <code>python3</code> 是 Microsoft Store stub（exit 49）</strong> → <code>.sh</code> 目標是 Mac/Linux 的真 python3；Windows 走 <code>.ps1</code>。</li></ul>

<blockquote>修改原則：所有東西都在 <code>canonical/</code> 寫一份，由 <code>install-personal</code> 物化到兩平台。改腳本後用隔離 <code>USERPROFILE</code> 跑 <code>install-personal</code> + <code>memory-lint</code>（fail=0）驗證，並保持 <code>bash -n</code> 乾淨。</blockquote>
