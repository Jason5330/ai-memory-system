🧠 記憶機制，最白話版

把它想成：一位私人助理幫你記筆記。你照常聊天，它邊聊邊記。

AI Memory System ・ 給 Claude Code & Codex

1分兩層 = 兩本筆記本

🧠 個人腦
記「你這個人」
你的習慣、你定的規矩。每個專案都通用，換專案還是懂你。
📁 專案腦
記「這個專案」
這個案子的決定、知識、進度。只屬於這個專案。
簡單記：個人腦 = 懂「你」　|　專案腦 = 懂「這個案子」

2記憶會分桶丟進

❤️ 偏好桶你喜歡怎麼做事（例：回答簡短一點）
📜 規矩桶以後一定要遵守的（你點頭批准過才進這桶）
📚 知識桶可重用的事實／工具用法／某個人事物
💬 對話桶每天聊了什麼的流水帳
🪞 反思桶助理自己檢討：做對／做錯／下次怎麼改
⛔ 壞工具桶哪個工具在你電腦壞了，下次自動避開

3平時對話，它做了哪些事

邊聊邊記 聽到值得記的（決定、習慣、解法）就丟進對的抽屜。純閒聊不記；連你回一句「好」，也會回頭看前幾句、記下你拍板了什麼。
偶爾大整理 回顧最近對話 → 反思 → 整理出「以後的規矩」建議給你。
你點頭 → 規矩永久生效 下次它自動遵守，不再犯同樣的錯。
重複的事變技能 同一招做過 2 次以上 → 幫你打包成一鍵技能。

4多久動一次？

⚡ 邊聊邊記：對話中即時（沒有背景程式在偷跑）。
🌙 大整理：可設成每天一次（預設建議凌晨 2 點），或你想整理時手動觸發。
✋ 其他（批准規矩、清空重來、看狀態）：你想做才做。
＊沒有「每幾分鐘掃一次」這種東西——就是「即時記 + 每天整理一次」。
👉 一句話：你照常聊天，助理邊聊邊把重點丟進對的抽屜（分「懂你」和「懂這專案」兩本）； 偶爾大整理一次，把你的習慣提煉成規矩、把重複的事變技能——所以越用越懂你、越來越好用。
