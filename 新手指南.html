一句話：這是什麼？

平常每開一個新對話，AI 就失憶，你得重講一次你是誰、上次做到哪。

裝了這套之後，Claude Code 或 Codex 會記住你的偏好、決策、知識，而且越用越懂你。

沒裝：你 →「幫我做 X」→ AI（完全不認識你）
裝了：你 →「幫我做 X」→ AI 先讀記憶 → 知道你是誰、你的習慣 → 給更準的答案

記憶分兩層（重要觀念）

  • 個人腦（~/.ai-memory）：你的偏好、行為準則、反思——所有專案共用、越來越懂你，永不進專案 git。
  • 專案腦（<專案>/.claude/memory）：那個專案自己的知識、對話。

安裝：兩個指令，別搞混

不是「裝兩次同一個東西」，是兩件不同的事：

跑幾次在哪跑給你什麼

init-project.ps1每個新專案各一次新專案資料夾裡那個專案自己的專案腦

順序：先 install-personal、後 init-project（init-project 會讀 install-personal 先放好的範本）。

# 1) 每台電腦一次：在框架資料夾裡跑
.\install-personal.ps1            # Windows
./install-personal.sh             # Mac/Linux

# 2) 每開一個新專案：進到「那個專案資料夾」再跑（不是框架資料夾！）

C:\Users\你的帳號\Desktop\ai-memory-system\init-project.ps1

九個指令（打在對話框，像打字一樣）

指令白話何時用
/capture把這次對話的重點存起來聊到值得記的、或某工具壞了
/ingest-sessions回頭把最近會話沒記到的補抓進來怕漏記；或交給每晚自動
/dream大整理 + 反思 + 提煉準則候選累積幾天後（或設每晚自動）
/harvest把重複 ≥2 次的流程變成 skill同個流程做過 ≥2 次（忘記也沒關係，capture 會主動問）
/review-doctrine逐條批准 AI 提的行為準則/dream 說有候選時
/status看現況（只看不改）想知道記了多少
/schedule-dream建立/列出/刪除每晚自動整理設一次；或要列/刪排程時
/reset互動式清空記憶、重新開始存了一堆不想要的記憶
/help列出所有指令 + 怎麼確認通關忘記怎麼用
Claude Code 打 /指令；Codex 用同名技能（講「capture 一下 / 跑 dream」即可）。最詳細的說明打 /help。

幾個重點：

  • 多久變一個 skill：同一流程出現 ≥2 次（同一天也算，不用等三天）就會被提議。建技能一律透過官方 skill-creator。
  • 工具一直壞掉（例如搜尋失敗）不是做 skill：那是工具失效 → 自動硬擋、改用能用的替代。直接 /capture 跟它說「這個工具壞了」，第 2 次就該擋。
  • 排程不會越堆越多：只維護一個排程；說「列出排程／刪除排程」就能管理（CronList 在 Claude Code CLI 不顯示、要去 VS Code 看）。
  • 🎭 AI 人設：你說「以後叫我老闆／講話直接點」這種「AI 該怎麼當」的話，會存進人設（個人層、每次載入），跟「任務偏好」分開。
  • 怕漏記：就算忘了打 /capture，/ingest-sessions（每晚也會自動先跑）會回頭讀最近的會話記錄把漏掉的補上。

每天怎麼用（最省事版）

第一次：設一次 /schedule-dream（每天自動整理）
每次重要對話結束前：打 /capture
看到「有 X 條準則待審核」：打 /review-doctrine 批准你認同的
覺得某流程重複做了：打 /harvest（或等 capture 主動問）

常見問題（極簡）

Q：怎麼確認裝好了 / 在運作？ 打 /status 看儀表板；或打 /help 看每個指令「怎麼確認通關」。

Q：會不會把資料傳出去？ 不會。全部存你自己電腦，純文字檔，不需網路、不需資料庫。

Q：記太多、存了不想要的怎麼辦？ 打 /reset——它會問你清哪一層、哪些種類，先備份、要打 yes reset 才動手，救得回來。

Q：我只回一句「好 / OK」也會被記到嗎？ 會。/capture 很聰明——它會回溯前 3-5 輪，把你拍板的決策實質存下來（選了哪個、為什麼、否決了什麼），而不是只存「好」。短但關鍵的決策不會漏，routine 閒聊還是會跳過。

Q：規矩是 AI 自己亂加的嗎？ 不是。它只能「提議」，一定要你 /review-doctrine 批准才生效。

Q：某個技能一直犯同樣的錯？ 它會自己學乖：/capture 記下失敗，/dream 寫進該技能的「失敗兜底」，下次自動避開。

Q：conversations / doctrine / persona… 這些英文看不懂？ 翻 記憶名詞對照表.md（每個分類中文白話＋例子），或打 /help 看「記憶分類速查」。

Q：換電腦？ 把 ~/.ai-memory（個人腦）複製過去；專案腦跟著專案走。

只要記住這一件事

每次重要對話結束，打 /capture。 其他的系統會幫你搞定；忘記指令就打 /help。
