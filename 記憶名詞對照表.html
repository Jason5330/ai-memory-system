記憶名詞對照表（這些英文是什麼意思？）

這套系統把記憶分門別類存放，名稱多為英文。這頁用白話一次說清楚：每個分類是什麼、存在哪、舉個例。
看不懂哪個詞就翻這頁；在框架裡打 /help 也有速查小表。

先懂：記憶分「兩層」

層中文白話存在哪
Personal個人腦關於「你這個人」——所有專案共用、越來越懂你~/.ai-memory/
Project專案腦關於「這個專案」——只屬於這個專案<專案>/.claude/memory/

再懂：記憶分「四種類型（type）」

type中文是什麼
user用戶你是誰、你的偏好、AI 的人設
feedback反饋/準則AI 以後該怎麼做（你批准的行為規則）
project專案你正在做的東西
reference參考工具 / 概念 / 人物等外部知識

逐個名詞：中文 + 白話 + 存在哪 + 例子

英文名中文白話解釋存在哪例子
conversations對話紀錄每天聊了什麼的流水帳（按日期一檔）conversations/YYYY-MM-DD.md「2026-06-02 討論了用 PGLite」
knowledge知識頁可重用的事實／工具用法／某個人事物（含「當前狀態＋時間軸」）knowledge/<名>.mdbun.md：「Bun 在 Windows 要加 --ignore-scripts」
reflection反思日誌AI 自己檢討：做對什麼、卡在哪、下次怎麼改reflection.md「用戶常問為什麼 → 我該主動說原因」
doctrine行為準則你批准過、AI 以後一定遵守的規則doctrine.md「回答先講結論再解釋」
doctrine_candidates準則候選還沒批准、等你審核的提議（/review-doctrine 審）doctrine_candidates.md「建議：程式碼一律附測試」⏳ 待審
preferences（feedback_user_style）偏好你喜歡任務怎麼做feedback_user_style.md「回答簡短、用繁體中文」
persona人設AI 該怎麼當（怎麼稱呼你、語氣、定位）—跟「偏好」分開persona.md「叫我老闆、語氣直接、當工程副手」
blocked-actions壞工具登記哪些工具在你電腦壞了、要被硬擋、改用替代blocked-actions.json「WebSearch 壞了 → 改用 WebFetch」
MEMORY.md記憶索引記憶的目錄（每次對話自動載入，AI 靠它找東西）MEMORY.md（列出上面各檔的連結）
skills技能把重複做的工作流封裝成「一鍵手冊」，以後自動觸發~/.claude/skills/、~/.agents/skills/「PR 摘要產生器」

「我這句話會被分到哪？」（情境 → 分類）

你說的話會進哪個分類
「回答簡短一點」preferences 偏好
「以後叫我老闆、講話直接」persona 人設
「以後解釋都要先講結論」（你批准後）doctrine 行為準則
「Bun 在 Windows 要加這個參數」knowledge 知識頁
「這個搜尋工具一直壞」blocked-actions 壞工具登記（硬擋）
「就用 PGLite 吧」（拍板決定）conversations 當天紀錄裡的 💡 決策
「我在做一個記帳 App」project 專案知識頁

一句話記住

  • 偏好 vs 人設：偏好＝「任務怎麼做」；人設＝「AI 怎麼當」。
  • 反思 → 準則候選 → 準則：AI 先反思 → 提議 → 你批准 → 才變成永久遵守的準則。
  • 知識頁先讀「當前狀態」（最新真相），要歷史才翻「時間軸」。
  • 看不懂任何分類 → 打 /help，或回來翻這頁。
